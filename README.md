## How I pick up new technology

I started at Microsoft in C++ on the Windows team. When I moved to PowerPoint, we had a week or two to learn Android before shipping features in Java. After that came Lumia and the Windows immersive apps in C++ and XAML, then PowerPoint test automation in C#. Since then I've shipped production systems in Spring Boot, .NET, Node.js, React Native and Flutter.

What carries over is the fundamentals: data structures, memory, concurrency, and how queues, caches and databases behave underneath. A queue works the same way on Azure, AWS or RabbitMQ; only the API changes. So when a project needs a framework I haven't used, I learn how it works underneath and I'm shipping within a week or two.
